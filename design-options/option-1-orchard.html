Featured project · Humanitarian tech

Reading minefield records so deminers can move faster

An AI document-understanding system that supports humanitarian demining operations in Bosnia and Herzegovina.

  • Python
  • FastAPI
  • YOLO
  • TensorFlow
  • OpenCV

Challenge

Minefield records hold critical handwritten data that has to be digitised. Manual transcription was slow, error-prone, and held up life-saving work.

Solution

YOLO object detection combined with custom TensorFlow models for handwritten text recognition, served by a FastAPI backend that processes documents in real time.
