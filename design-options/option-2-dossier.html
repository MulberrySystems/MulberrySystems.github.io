Reading handwriting on the records that clear minefields

The project we're proudest of, and a fair summary of how we work: a hard recognition problem, a real operational constraint, and a system that runs every day.

Reference

MBS-CF-04

Domain

Document understanding, computer vision

Delivery

Model, API and processing pipeline

Challenge

Minefield records contain critical handwritten data that must be digitised to support demining operations. Manual transcription was slow, error-prone, and created bottlenecks in life-saving work.

Solution

An AI system combining YOLO for object detection with custom TensorFlow models for handwritten text recognition. A FastAPI backend processes documents in real time.

Processing pipeline

  1. IngestScanned record enters the API
  2. DetectYOLO locates fields and handwriting regions
  3. RecogniseTensorFlow models read the handwritten text
  4. StructureResults returned as structured data
