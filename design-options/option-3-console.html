AI that reads minefield records so deminers don't have to.

Humanitarian tech · Bosnia and Herzegovina

AI-Powered Minefield Documentation System

Challenge

Minefield records hold critical handwritten data that has to be digitised to support demining. Manual transcription was slow, error-prone and held up life-saving work.

Solution

YOLO object detection combined with custom TensorFlow models for handwritten text recognition, behind a FastAPI backend that processes documents in real time.
